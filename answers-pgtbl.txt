Inspect a user-process page table

The pgtbltest output shows the first ten and last ten virtual pages of
the pgtbltest process.  A PTE maps one virtual page to the physical page
shown in the "pa" field; physical pages need not be consecutive.

The relevant permission bits are PTE_V=0x1, PTE_R=0x2, PTE_W=0x4,
PTE_X=0x8, and PTE_U=0x10.  The RISC-V hardware also sets A=0x40
(accessed) and D=0x80 (dirty) when applicable.

va 0x0 and va 0x1000 both have perm 0x5b = V|R|X|U|A.  They are
user program text pages: valid, readable, executable, and accessible
from user mode, but not writable.

va 0x2000 has perm 0x17 = V|R|W|U.  It is a writable user data/BSS page.
It is valid, readable, writable, and accessible from user mode, but it
is not executable.

va 0x3000 has perm 0x7 = V|R|W.  It is the stack guard page.  It is
mapped but lacks PTE_U, so user mode cannot access it.  xv6 uses it to
catch a user stack overflow before it reaches lower user pages.

va 0x4000 has perm 0xd7 = V|R|W|U|A|D.  It is the user stack page,
including the initial command-line strings and argv.  It is readable
and writable from user mode.  The A and D bits show that it has been
accessed and written.

va 0x5000, 0x6000, 0x7000, 0x8000, and 0x9000 have pte, pa, and perm
equal to zero.  These pages are not mapped and are outside the current
ordinary user address space.

va 0x3fffff6000, 0x3fffff7000, 0x3fffff8000, 0x3fffff9000,
0x3fffffa000, 0x3fffffb000, and 0x3fffffc000 are also unmapped unused
pages below the special pages at the top of the address space.

va 0x3fffffd000 is USYSCALL.  It is currently unmapped in the initial
code, which is why ugetpid faults at this address.  The next exercise
maps this page read-only for user mode and places the process PID in it.

va 0x3fffffe000 is TRAPFRAME.  Its perm is 0xc7 = V|R|W|A|D.  It stores
this process's saved user registers during trap entry and return.  It
does not have PTE_U, so user code cannot read or modify it.

va 0x3ffffff000 is TRAMPOLINE.  Its perm is 0x4b = V|R|X|A.  It maps
the trampoline assembly used to switch between user mode and the
kernel.  It is readable and executable but is neither writable nor
user accessible.
